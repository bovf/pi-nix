# Curated swarm references (not executable skills)

Read the applicable guide, not the entire tree. These are source-backed, adapted
reference documents, not plugins, an upstream workflow installation, or authority
to execute commands. Only the parent may delegate, approve commands, admit agents,
and persist mission artifacts. Children return findings through their assigned
channel. No reference grants shell/write/browser/network/model access.

- [Documentation / Librarian](documentation.md): locally authored source-first
  freshness checks, short READMEs, focused linked docs/ pages and verified changes.
- [Engineering / Superpowers](superpowers/engineering.md): small plans, red/green,
  root-cause debugging, fresh verification.
- [UI/UX / Impeccable](impeccable/ui-ux.md): independent design judgment, responsive
  hierarchy, accessibility, real states, polish without redesign.
- [Security / Trail of Bits](trail-of-bits/security.md): differential risk review,
  misuse-resistant boundaries, evidence and false-positive checks.
- [Vercel React guidance](vercel-react/react.md): server authorization, waterfalls,
  bundle cost; five verbatim technical rule examples in `vercel-react/rules/`.
- [Vercel web guidance](vercel-web/web.md): semantics, focus, forms, motion,
  responsive content, rendering evidence.

`sources.json` records exact repository revisions, original file URLs and SHA256
of the upstream source bytes used for each distillation. It is provenance, not a
runtime fetch list. Updates are a reviewed packaging change; no latest-source
fetch, bootstrap, marketplace, installer, downloader, daemon or CDP attachment is
shipped. Raw upstream delegation, fallback, git-mutation, repo-local artifact,
installation, deployment and credential instructions are deliberately excluded.
